Bluegrass Basketball Briefing is an automated daily post about Kentucky men's basketball. Each morning a pipeline pulls box scores, play-by-play, advanced ratings, beat-writer articles, podcast transcripts, and recruiting news, then assembles a structured Briefing covering the previous day. A verification pass strips any claim the sources don't support before publishing.

Sources include ESPN, Sports Reference, Bart Torvik, EvanMiya, Kentucky Sports Radio, A Sea of Blue, Wildcat Blue Nation, the Lexington Herald-Leader, 247Sports, and a rotating set of YouTube channels.

This is a personal site. It has no affiliation with the University of Kentucky.
